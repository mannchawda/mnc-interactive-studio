# MNC. Interactive Studios

> **We Build Worlds.** — Game Development · 3D Art & Assets · Web Development

Live site: [mnc-interactive-studio.vercel.app](https://mnc-interactive-studio.vercel.app)

---

## About

MNC. Interactive Studios is an independent creative studio founded by Mann Chawda,
specializing in game development, 3D art, and full-stack web development. This is
the official studio website — built from scratch with zero frameworks, zero templates,
and zero shortcuts.

---

## Tech Stack

| Layer      | Technology                        |
|------------|-----------------------------------|
| Structure  | HTML5 (semantic)                  |
| Styling    | CSS3 (custom properties, grid)    |
| Scripts    | Vanilla JavaScript (ES6+)         |
| Canvas     | HTML5 Canvas API (2 instances)    |
| Fonts      | Orbitron · Syne · JetBrains Mono  |
| Hosting    | Vercel                            |

**Zero dependencies. Zero npm. Zero build step.**

---

## Features

- 3D interactive particle grid in hero (canvas, mouse-reactive)
- Glitch text animation on studio name
- Typewriter effect cycling through services
- Custom cursor with smooth lag ring
- Animated starfield background
- Scroll progress bar
- 3D card tilt effect on hover (perspective transform)
- Marquee ticker strip
- Animated stat counters on scroll
- Scroll-triggered reveal animations (IntersectionObserver)
- Active nav link tracking
- Mobile responsive with hamburger menu
- HUD corner decorations (sci-fi aesthetic)

## Local Development

No build step required. Just open in browser:
